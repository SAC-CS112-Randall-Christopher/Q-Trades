# CP12: after-cost memory and a bounded entry filter

The normal Historical matches screen freezes a chronological memory comparison,
queues it through the existing experiment registry/limited child, and reopens the
saved result. Numerical history (B) and measured local context (C) share opportunities
with the existing no-filter baseline (A). Missing targets yield a retained
insufficient result. Existing source has no qualified memory strategy or proven
account benefit; the operating six-account trial is unchanged.

## Executable targets and their limits

`memory_dataset.py` reads the existing immutable archive. Price-path outcomes are
not executable targets. A target requires the first recorded breakout-v1 buy intent
in dispatch order, its actual modeled paper fill, a linked complete closing trade,
reconciled same-engine state/events and a subsequently observed matured 45-minute
horizon. The target is `(proceeds - filled cost) / filled cost`, in basis points;
fees/slippage in those amounts are embedded once. Sibling account clones do not
create additional labels. The selected intent is fixed before either fills or
outcomes, including nonfill failures. Missing books, unsupported versions,
unreproducible features, open/partial trades and missing maturity remain unknown.

These targets describe recorded taken trades and retain selection bias. They do
not reconstruct unexecuted opportunities or claim a continuous counterfactual
horizon. A ledger-linked trade target is not a whole-account return. Consequently
the current experiment withholds whole-account effect, exposure/cash controls,
monetary marginal host cost and forward qualification. No profitable price-only
proxy, reject-everything victory or apparent win-rate improvement fills these gaps.

The source corpus has at most 512 episodes. An aggregate byte query checks the
entire permitted execution dependency set before decoding it; above eight MiB,
all episode descriptors stay represented and executable labels are unavailable.
There is no hidden first-N source substitution. Within that budget, each recorded
engine transition is verified once and reused across episode-label checks. All
frozen inputs remain in the existing eight-MiB/512-MiB experiment registry; the
single two-processor/IDLE child, 256-MiB sampled supervision and 25-second limit
remain unchanged. An oversized result or interrupted attempt stays visible.

## Frozen estimator and chronology

The estimator starts with a no-filter diagnostic and a fixed simple direction
filter. A is not replaced by a complex model. B uses ten price-relative minute
returns. C adds observed volatility magnitude, spread and visible-depth imbalance;
absent context is unknown. All scaling uses only the training partition and rejects
unstable/zero-variance coordinates. The frozen pilot has a seven-day chronological
calibration partition and 3300-second purge before each subsequent partition,
twelve training, six calibration and eight protected test groups, and at most
128 chronological training groups. This cap is a declared library rule, not an
outcome-selected sample. Changing the library/cap is a new protected experiment.

Five equally weighted, temporally separated neighbors are selected without their
outcomes. Only then are available net targets joined. Distance thresholds and the
five-group/20% concentration rule are fixed in `memory-entry-v1`. Supported,
weak-support, unfamiliar, invalid-input and late-result states remain distinct.
Expected net trade return, unfavorable neighbor, range, dispersion, distinct groups,
days and similarity are descriptive diagnostics. Recognition confidence is unknown.
Illustrative favorable/unfavorable cases never rebalance the representative sample;
no close failure example cannot establish safety.

Three fixed positive-fraction calibration bins use the separate chronological
partition, with Laplace smoothing and at least three calibration observations per
bin before publishing a probability. Protected test Brier/error metrics remain
separate from resemblance and account economics. Sparse calibration produces
unavailable probabilities, not confidence. Both calibration and target availability
must precede a query. Full test predictions and failures are retained within the
result budget. A-to-B/B-to-C receipts preserve changed entry decisions, coverage,
missed positive trades, unresolved exposure/turnover, uncertainty and marginal cost.
The CP7 matched daily operating allocation is not silently changed or charged twice.

## Deterministic integration

The typed frozen artifact extends the existing numerical validation/admission
adapter, with B/C identity, immutable retries and the same four retained admissions
and twenty retained accounts. No automatic admission occurs. The normal API refuses
synthetic or economically unqualified memory admission. Disposable tests exercise
the existing isolated paper adapter and all financial invariants; this is distinct
from a usable qualified paper candidate, which has not been established.

If a memory artifact is eventually separately qualified/admitted, its bounded
calculation runs on the existing closed-bar feature path, outside position ticks.
Only a supported negative quality result suppresses an otherwise eligible entry.
Unavailable optional memory supplies no additional signal; baseline cash/risk,
freshness and market gates still apply. Base ATR, stop/progress/45-minute hold and
sizing remain intact. Invalid memory does not create a model-driven exit or fresh
loss budget. Exact as-seen memory inputs, completed availability and measured
inference time are saved; financial dispatch is never backdated to the start of
calculation. Replay reproduces the memory input/forecast before claiming an engine
baseline match. API inspection/reopen cannot train, fund, promote or place orders.
