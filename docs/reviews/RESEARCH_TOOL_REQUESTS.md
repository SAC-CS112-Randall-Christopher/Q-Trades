## Operator path

An explicitly selected successor profile can return `request_tool` with a typed
kind (`strategy_family`, `feature`, `analysis_tool`), identifier, purpose, required
inputs and acceptance checks. The original question, evidence citations,
falsification and rationale stay attached to the immutable model response and
saved task. The existing worker records `tool_wait` / `waiting`; the ordinary
Local model research panel shows **Tool requested · pending implementation
review**. It does not install code, execute a tool, create a trading account or
dispatch another model request. Reload and registry restart reopen the same
request. Such waits do not enter the data-resumption or mature-comparison
follow-up selector.

The dashboard also displays server-observed running, queued, waiting, idle,
paused or unavailable activity independently of model readiness. Counts apply
to the current execution mode and pilot grant. Missing activity is unavailable,
and a failed refresh labels the retained observation as historical. An enabled
worker with no eligible continuation is idle; it is not continuing learning.
Opening historical detail separately explains whether its frozen instruction
contract matches the selected worker, differs, or cannot currently be read.
This is a read-time applicability disclosure; it never rewrites the recorded
reason, status, context, result, attempts or allowances. Older work stays inactive
during a contract replacement and reopens with its original facts.

This delivery records requests awaiting implementation review. It does not yet
deliver approval/disposition controls, tool implementation, tool installation,
or automatic resumption after implementation. Implementation and subsequent
investigation need their reviewed capabilities, source evidence and applicable
authority. Existing outcomes are retained if the request occurs at follow-up.

## Explicit contract boundary

The default `reviewed-rule-role-v5` prompt/schema/packet and literal contract
hash remain unchanged. V5 and its original task/profile/grant/consumed attempts
are not reinterpreted. New behavior uses `reviewed-rule-role-v6` explicitly:

- The researcher receives a frozen inventory derived from its issued catalog,
  offered feature fields and existing reviewed input/comparison methods.
- `unsupported_capability` identifies the exact missing kind/identifier;
  `request_tool` identifies the desired absent item and its proposed test.
- An offered identifier cannot be claimed absent. Strategy-family consistency
  is also checked directly against the offered capability catalog.
- Current entry ineligibility or missing outcome evidence does not make an
  implemented family unavailable. A missing supported source/interval uses the
  existing offered typed `request_data` requirement.
- A request can ask for a missing feature within an offered strategy family.
  Capability comparison `kind=independent` does not mean its family is absent.
- Both roles require the exact v6 packet tag. Reviewer packets keep their
  existing review schema and do not require a researcher inventory.

The existing v1 paper-pilot grant remains exactly eight keys. An explicit v2
grant adds `role_contract=reviewed-rule-role-v6` and must bind its new exact
profile digest. It retains the same model/base/adapter/runner, CPU/priority,
memory reserves, time/context/output and hourly budgets. The default v5
development transport refuses v6 inputs. Existing local-role qualification
also binds the explicitly selected contract. Preflight rejects mismatched
packet/profile identity before a model attempt or allowance is reserved.
No operating grant/profile/configuration is changed by this source delivery.

Typed-key consistency is a factual boundary, not a language-understanding or
research-usefulness score. Citations must identify supplied evidence, but these
checks do not prove the prose is supported, the requested tool is necessary,
or the idea improves after-cost results. Requests require implementation review;
experiments retain the deterministic method, independent review, frozen costs,
ordinary paper admission, genuine outcome and existing continuation owners.
