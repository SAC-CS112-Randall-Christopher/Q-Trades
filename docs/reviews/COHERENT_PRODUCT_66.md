## Financial and control boundaries

Overview and navigation reads do not select a question, dispatch a model, prepare
an experiment or write financial state. Reads have bounded projections and
component-specific unavailable states. Eight oldest active investigations remain
visible even when newer terminal rows occupy recent history. Ordinary selection
waits are distinguished from recovery failures; the model's working label follows
its actual processing lease.

Startup binds the reviewed scope, control revision, policy and comparison revision.
A later Pause invalidates an old review even when the permission was already
disabled. Finite, expired, manual and closed-resource authorities cannot be
silently widened. Pending commands retain their original binding; an uncertain
acknowledgment is reconciled through exact reads, not automatic replay on mounting.

Fixed-rule admission verifies the immutable original reservation, unique mature
score, proposal and rule identities. It freezes original risk/cost/funding,
current incumbent/control configuration and implementation provenance. Separate
candidate/control funding respects twenty managed/reserved places and any stricter
active policy. Historical losses, source accounts, attempts and operating costs
remain intact. No numerical artifact is invented for a RuleSpec.

Repeated committed admission recovers the same pair even after fresh eligibility
changes. Unavailable or changed implementation blocks these forward accounts'
new entries and designation while existing exits/stops continue. Designation
still requires the existing protected subsequent evidence policy and exact
explicit approval; rollback changes the role pointer without transferring money.
