The ordinary paper lab can compare a preserved parent with a child adding only
the existing `memory-entry-v1` filter. `reviewed-lab-rules-v3` embeds the validated
frozen artifact, genuine 2700-second horizon, net-basis-point units, explicit
unchanged-baseline fallback and declared marginal daily cost. Legacy v2 omits the
new field entirely, preserving its original serialization and fingerprint.

The filter can reject an already eligible baseline entry. Missing, unfamiliar,
late or invalid data supplies no additional signal. It cannot create an entry,
alter exits/sizing or bypass the original hard risk stops. Medium and long rules
remain unchanged; a short artifact cannot be renamed into a longer model.

`rule_components.reviewed_feature` is the single pure causal adapter used by the
prospective evaluator, role evidence, actual paper runtime and saved feature
reproduction. The recorder and replay bind its source plus memory/spec versions.
Reproduction refuses modified component decisions; executable account replay
still requires complete financial input chronology and appropriately recorded
books. No price-only return is presented as an executable result.

with a valid permitted memory artifact and explicit numerical/contextual daily
cost in the frozen completed memory experiment plan. Synthetic artifacts cannot
enter observed-market reservations. Missing fitted data/cost leaves that
capability unavailable. The role contract is v5: prior qualifications are stale.

The child delta is this component plus its additive contract version. Parent
reference, horizon, fields, holdings/funding/history and risk stay frozen. Common
costs stay equal; marginal component cost is reported and subtracted once from
the corresponding candidate/reference, with full-period passive and cash.

synthetic causal bars, exact replay reproduction/corruption refusal, legacy

parent/child admission and separately recorded negative whole-account cost.

missing-cost scenarios. No real eligible fitted artifact, qualified model
