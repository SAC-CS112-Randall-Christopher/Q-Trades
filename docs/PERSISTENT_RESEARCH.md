## Operator path and recovery

Open **AI Lab → Knowledge & reviews**. Import a complete permitted text/Markdown/
HTML section or native PDF selection; retain title, author, origin, category,
market/horizon applicability, publication date and rights. Receipt time comes from
the owner, independently of the publication date. Corrections append a version.
The original PDF can be downloaded byte-for-byte. Scanned/encrypted/unreadable
PDF pages are unavailable; no OCR or content is invented. Extraction runs in an
owned child with a ten-second deadline and 256-MiB job limit. Text is capped at
64 KiB, PDF at 128 KiB and six pages. Sources/HTML/model output are untrusted data.

URL acquisition requires approval of the exact public HTTPS document and its
rights. It refuses credentials, query tokens, private/nonpublic addresses,
redirects and compressed responses. The checked public IP is pinned while TLS
uses the original host. No model tool can choose a network target or import files.
DNS resolution relies on the Windows resolver, with a five-second caller wait.
An OS lookup cannot be cancelled safely; at most one unfinished daemon lookup
can remain, and further URL imports show its occupied slot. A late result cannot
initiate a fetch or import. Socket/read/content processing has separate limits.
Large documents need deliberate sections.

Use **Research reviews** to reopen the frozen packet, all delivered source
contexts, original response, provider turns, usage, calculated cost, dispositions
and pending continuation. A schema-valid response is a model-assisted draft;
citation identity is checked mechanically, and semantic support still requires
independent review. Acceptance creates a local annotation with explicit origin
and preserves original financial facts/answers. A rights description changed by
an upgrade does not rewrite an already-owned original annotation.

The existing teaching flow creates an instructional candidate only after an
accepted review and explicit original/current teaching rights for every delivered
source, including later tool reads. It keeps model-assisted authorship and source/
research family grouping. Review of the target, preflight, preparation, actual
training and operating promotion remain their existing separate gates.

Use **Connections & schedule** to select one execution owner, actual verified API
model/reasoning/project/prices, bounded scope and rolling request/token/cost limits.
**Run due review** shares the background scheduler's durable occurrence and claim.
An overlapping click cannot classify another invocation's active request as
interrupted. Only the invocation that wins that request's dispatch transition
may finalize its unfinished outcome; a genuine timeout/cancellation keeps the
request uncertain and its spend reserved for reconciliation.

The existing scheduler examines at most sixteen completed tasks per pass. It
skips unchanged or nondisclosable candidates using per-task checks, retaining a
single durable cursor in the registry so older eligible work remains reachable
after restart. The `(updated, id)` cursor seeks through an index, including tied
timestamps, rather than scanning the preceding archive. An exhausted window
shows a bounded continuation reason. Existing in-flight/uncertain work, provider
backoff and spending limits stop acquisition before rebuilding candidate packets.
At most one request is dispatched for the daily occurrence; advancing the cursor
does not create a new spending allowance. Relevant changed evidence remains
eligible on a later available occurrence.

The provider credential is stored under the current Windows user's DPAPI identity,
with directory-bound entropy. It is cleared from the password field before the
request, never kept in browser storage, and not part of model/tool packets. A
missing/different user identity requires explicit credential repair. The scoped
connection test uses and revokes a short-lived CP22 claim and makes no paid call.
It proves app-local discovery/read only, not external account or tunnel support.
Credential renewal uses a unique owned staging file. A failed replacement keeps
the prior key and removes only that attempt's staging file; a legacy abandoned
staging file is preserved and cannot block renewal.

Closing the browser leaves the existing API/Windows supervisor running. Sleep,
power-off and sign-out remain unavailable intervals. One latest due occurrence
coalesces missed days; Denver/DST dates are durable, and model changes cannot
repeat the same paid occurrence. An unchanged completed watermark skips work.
The app owns a deadline, tool/byte/turn limits and prompt/output cost reservations.
Pauses/permission changes/current resource admission are checked before each
provider turn. Prior RAG derivation sources remain revocable even when a new
search would omit them. No private localhost is handed to an external provider.

A known refusal before a provider marker is **blocked**, with known zero provider
usage. A dispatched request with uncertain completion is **unknown** and stops
new chargeable work. Unknown spend remains reserved. Retained final provider
turns can be revalidated locally after a lost commit/acknowledgment. Otherwise the
operator acknowledges uncertainty, without replaying a paid request or inventing
an answer/refund. 401/403/429 and Retry-After are retained separately. Measured
usage is retained as turns arrive; an over-budget report stops further turns.
Completed known costs use configured verified prices; this is a calculation,
not an assertion about an independently reconciled provider invoice.

**Rebuild search index** changes derived data only. Eligible historical ranking
is rebuilt from canonical cutoff-eligible passages, and still works if the saved
FTS index is missing. **Back up library** uses SQLite's coherent backup API and a
checksum manifest. **Restore fresh snapshot** verifies originals/integrity and
rebuilds indexes in a new owned SQLite file; it never overwrites the active
library or research records. The existing storage/volume/reserve checks and
experiment-registry ceiling are unchanged. Library/quota failures remain visible;
there is no automatic cleanup, hidden spill or quota increase.
