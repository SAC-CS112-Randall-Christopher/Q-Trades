## Evidence and performance boundaries

Unknown confidence remains **Not calibrated**. Synthetic or insufficient forward
reports stay **No promotion**, with incumbent approval disabled. Qualification
changes a paper research role only; the dated readiness packet remains **Not
ready** for live execution.

The chart joins contiguous reported window checkpoints. Unavailable windows break
the line. A funding change may move equity; the graph is not a continuous price or
funding-adjusted return series. Provisional windows, unknown operating costs and
last-reported balances remain labeled. Separate simulation balances are not a
realizable combined portfolio.

Only the active screen is mounted. Status requests run serially every three
seconds, or ten while hidden; unmounts abort requests. Dashboard public watchlist
requests run every two seconds, and strategy evidence does not mount hidden market
charts. Research keeps the audited serial polling and frozen backend contracts.
These are implementation bounds, not measured browser latency claims.

The new stylesheet covers existing research/review components and responsive
navigation. Narrow tables scroll within their containers. Focus outlines, a skip
link and reduced-motion preferences remain available.
