# CP5 distinct numerical challengers

Slower one-hour direction, volatility expansion and range-conditioned reversion
are separate mechanisms with explicit entry/no-trade rules, horizons, failure
regimes and cost hurdles. Their frozen common evaluation group includes constant
and rule-only controls, cash, descriptive nonoverlapping-label errors, three
predeclared threshold neighbors per family, and doubled fee/slippage stress.
All nine trials remain part of one search group; none is independent confirmation.
The fit and standardization use training data only, with the longest label horizon
reserved/purged before evaluation. History gaps and original availability remain
binding. Revised rows do not replace earlier input versions.

The UI can freeze the group, inspect all results and failures, export it, and
explicitly admit a fitted artifact to a separate $50/$100 exploratory paper account.
An unfavorable fit can still be explored prospectively with explicit operator
admission; it is never qualified or promoted by that action. Funding/admission is
idempotent in the existing PostgreSQL transaction. The old primary and original
funding/loss policies remain unchanged. Four admissions are retained, never pruned.

Forward adapters read the same persisted minute-quote feature semantics used during
fitting, not substitute candle-close inputs. They perform only bounded arithmetic;
no fit, model request or LLM enters order management. Prediction plus mechanism
gating feeds the existing reservation/fee/depth/fill/risk engine. Missing inputs or
invalid models disable new numerical signals; exits remain deterministic. Stops,
time exits, cash-only checks, precision and displayed-depth participation remain in
the existing engine. Account journal/pauses/recovery are normal UI controls.

Minute quotes lack price-level historical books. The evaluator explicitly refuses
an execution replay instead of inventing profitable fills from those quotes. The
software replay/risk/fill path is tested with declared synthetic books; actual
forward account results require subsequent observations and CP7 comparisons.
Rotation, order-flow, maker inventory, arbitrage, news and RL remain data-gated.

Predeclared bounds remain CP4's queue/time/input/storage limits; three fits and nine
sensitivity diagnostics per group, one input query per minute when admitted models
exist, at most 121 retained input events on the signal path, no paid inference.
The finite CP8 benchmark/audit measures integrated resources and retained limits.

The initial seven candidate tests failed when their fixture assumed the retained
gapped market history was sufficiently contiguous. The production gap rule remains
unchanged. Separate synthetic contiguous data exercises complete fitting/admission;
a regression test preserves the real-history insufficient-data rejection. Original
preflight reproduction remains exact. These checks are software evidence, not a
successful research discovery. Source/build/full/database/browser receipts accompany
the draft and the final stack audit. No merge or installation occurs here.
